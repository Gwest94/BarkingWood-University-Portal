# Barking Wood University Portal
A full-stack university management and student portal web application built with **React.js** and **Supabase/PostgreSQL**, featuring comprehensive role-based access control (RBAC) and database-driven CRUD operations.

## Features
- **Role-Based Authentication:** Secure login architecture separating student portals from administrative management views.
- **Student Dashboard:** View active enrollment statuses, real-time cumulative GPA (CGPA) calculations, semester results, and interactive course registration modules.
- **Administrator Dashboard:** Comprehensive record management interface empowering administrators to modify student profiles, view individual academic results, and manage database records with action controls (Modify, View Results, Delete).
- **Secure Backend Integration:** Connected to a PostgreSQL database via Supabase, protected with Row Level Security (RLS) policies.

## Tech Stack
- **Frontend:** React.js, JavaScript (ES6+), CSS3, Responsive UI/UX Design
- **Backend & Database:** Supabase, PostgreSQL, RESTful APIs, RLS Security Policies
